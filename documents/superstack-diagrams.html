02

What happens on every prompt

The router's seven steps, run in order, every single time you type something into Claude Code.

0
always-on

Discipline layer loads

Karpathy guidelines apply automatically: no silent assumptions, goal-driven execution, anti-overcomplication, never rewrite code you don't understand.

1
silent · 0 tokens

Memory-first check

Reads .vault/hot.md, .vault/index.md, and queries graphify for relevant files — before ever asking you for context.

2
always-on

Ponytail auto-levels

Quick fix → ultra · normal feature → full · complex/unfamiliar → lite. Overridable any time with /ponytail <level>.

3
routing

Intent routing

Your prompt is matched against the intent table and mapped to a tool chain — e.g. feature + UI work routes through GSD, ui-ux-pro-max, Superpowers, and ECC in sequence.

4
confirmation gate

Preview + confirm

One line per command, plus a file-count estimate. /skip waives it for normal tasks only — heavy (>10 files) and destructive actions always show, no exceptions.

→ /gsd-plan-feature (structure work)
→ uipro search "auth form" (design pattern)
→ /execute-plan (build) → /ecc:code-review (verify)
~4 files affected. Proceed?
5
execution

Execute the chain

Skills auto-apply, agents launch where relevant, output stays minimal (ponytail), ECC quality gates verify before anything is declared done.

6
silent write-back

Memory updates

.vault/hot.md gets a short summary, .vault/index.md updates if new topics appeared, changed files are noted for the next graphify pass. Never announced.
